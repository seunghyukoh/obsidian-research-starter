# Research workspace

**Read → highlight → search → connect → write.**

Start with the [setup guide](README.md) if this is your first visit.

## Try the workflow

1. Open [[papers/Highlight Playground.pdf|Highlight Playground]].
2. Highlight the five practice sentences using the five meanings.
3. Open the new `_highlights.md` note beside the PDF and search its contents.
4. Press **Option/Alt+Shift+T**, choose your integrated terminal, and run `codex`.
5. Ask it to write a short synthesis in `notes/` with links to the highlights.

## Try linking notes

Open [[Example Project]] and follow the links to [[Example Note A]] and
[[Example Note B]]. These are just short notes connected with wiki links.

To make your own link, type `[[` while editing and choose a note from the
suggestions. See [[guides/Linking Notes|Linking notes]] for a quick walkthrough.

Write your notes however you like. The examples are optional.
