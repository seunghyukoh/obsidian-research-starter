# Papers

Save PDFs here. Easy PDF Highlight creates `<filename>_highlights.md` beside
each PDF when you make the first highlight. Keep those files together.

Start with [[papers/Highlight Playground.pdf|Highlight Playground]], an original
practice document included with this starter. It contains selectable text and
no pre-created highlight note, so you can try the complete first-use workflow.

Use names that make sense to you. You can link to a PDF from any note using
the same wiki-link syntax. See [[guides/Linking Notes|Linking notes]] and
[[guides/Reading Workflow|Reading Workflow]] for color meanings and search examples.
